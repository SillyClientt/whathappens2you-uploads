# WhatHappens2You uploads

Public storage for **finished, approved** WhatHappens2You videos. Metricool downloads each video from here
to post it on YouTube, Instagram and TikTok.

- `videos/YYYY-MM-DD_<slug>.mp4` - one approved video per file (GitHub limit: 100 MB per file).
- `branding/` - profile picture.
- Raw link: `https://raw.githubusercontent.com/SillyClientt/whathappens2you-uploads/main/<path>`

This repo is public. Only finished videos go here - nothing else.
